# PUSYA PET

Тамагочи-расширение для SillyTavern. Питомец живёт по реальному времени, лезет в сцену и реагирует на то, что происходит в чате.

## Что умеет

- 8 архетипов (собачьи, кошачьи, птицы, грызуны, рептилии и др.), каждый со своим темпом жизни и повадками
- 5 характеров: спокойный, игривый, вредный, пугливый, ласковый
- 4 возрастных стадии: детёныш → подросток → взрослый → пожилой
- Реальное время: голод, энергия, чистота и настроение меняются, даже когда чат закрыт
- Модель-наблюдатель: раз в N сообщений модель смотрит сцену и решает, что делает питомец
- Своя модель: можно подключить дешёвую модель (DeepSeek, Gemini и т.д.) отдельно от основной
- Облачное хранение по нику — питомцы переживут чистку кеша и переедут на другое устройство
- Пауза — можно остановить время, чтобы питомец не страдал, пока тебя нет
- Несколько питомцев в одном чате
- 8 тем оформления + свои цвета
- Перетаскиваемая лапка и панель

## Установка

1. Открой SillyTavern
2. Перейди в **Extensions → Install Extension**
3. Вставь ссылку на этот репозиторий
4. Перезагрузи страницу

Или вручную: скопируй папку в `SillyTavern/public/scripts/extensions/third-party/pusya-pet/`.

## Настройки

В панели Extensions появится секция **PUSYA PET** с тремя параметрами:
- **Вставлять питомца в промпт** — контекст питомца уходит в генерацию
- **Наблюдатель** — модель смотрит сцену и описывает действия питомца
- **Частота** — как часто наблюдатель срабатывает

Остальные настройки (скорость жизни, тема, своя модель, облако) — внутри самой панели питомца.

## Облако

Общее с Таво-версией. Один ник — одни питомцы на обоих платформах.
